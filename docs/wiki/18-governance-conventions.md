# 18 — 治理：口径定义 / 判据 / 脏数据红线（用户签字）

> 这份是**治理章程**，不是技术文档。AI 起草、用户签字。用户签的不是"算法对不对"
> （那是 AI + 确定性回算的事），是**"这个标准是不是事先定的、有没有在看到结果后被改过"**。
> 任何改生产行为的 PR、任何"丢哪些数据/选哪个判据"的决定，都要落到这里、对照这里。
> 起因：2026-06-13 口径审计发现一个根因 bug 让生产与全部回测的核心信号(regime/防御)
> 分叉，且差点把一个真信号当负面结论存档——治理空隙必须正式关闭。

## 1. 口径定义（单一可信源，禁止多处各写）

| 口径 | canonical 定义 | 单源位置 | 禁止 |
|---|---|---|---|
| forward return | **日历天**：base=≤asof 最后收盘，target=≥asof+Timedelta(days=N) 首收盘 | `core.regime_probability.forward_return` (PR #41) | `shift(-N)`(交易日) 冒充日历天 |
| "近 2 年"窗口 | **504 交易日**，滚动/`tail`，**非**全量、非 yfinance"2y" | `utils.market_metrics.TRADING_DAYS_2Y` | `(closes).mean()` 对全量算分位 |
| 价格分位 (price_quantile_2y) | 近 504 交易日内 ≤ 当前价比例 | `utils.market_metrics._calc_price_quantile`(tail 504) | 对 `get_history_data` 全量返回直接算 |

## 2. 判据标准（预注册，不许事后改）

- 任何验收/实验的判据(阈值、窗口、通过线)**跑前写死在脚本 docstring**，跑后不许动。
  先例：`scripts/fit_path_calibration.py`、`scripts/validate_gold_defense.py`、
  TA 实验 `eval_ta_signal.py` 的 Gate。
- **冻结自由度再回算**：实现者已知结局时，"看到结果再微调判据/阈值/窗口"是认知泄漏，
  比代码 bug 难防（不在代码里、在人脑里）。回算脚本里不许有跑后调整的参数。
- 判据冲突要显式记录并选定（例：黄金防御用 p_below 还是中位右偏——论文与本地曾不一致，
  未定死前 PASS/FAIL 都不算数）。

## 3. 脏数据 / 前视红线（最硬）

- **新闻/情绪/基本面类信息：只能用决策当时落盘的快照**。缺了标"缺失"，**绝不用今天重抓的补**。
  今天能捞回的"过去新闻"带事后修订、索引时间错位，且 AI 与用户都已知结局 → 重算得到
  前视污染的虚假好结果，且无法自证清白。修口径与重抓新闻在代码里只差一个函数调用，**盯死这条线**。
- **纯价格衍生量(VIX 分位、price_quantile、价格 regime 序列)可合法"覆盖过去"重算**：
  只依赖当天及之前收盘价，无前视、可复现（先例：`scripts/audit_convention_diff.py` 扩张窗 vs 滚动窗）。
- 缺失即缺失，不补值、不用未来均值回填。

## 4. 合并前置条件（生产行为变更）

任何改生产行为的 PR，**必须**附：
1. **一句话信号影响翻译**：「这个改动会让系统在哪些情况下，把原本的 X 信号变成 Y 信号」。
   答不出 = 实现者不知影响面 = 不该合。
2. **确定性回算差异报告**（纯价格类可回算时）：列出过去 N 天里哪几天信号会变、为什么，
   人话呈现（不是分位数字）。用户判断报告自洽性，不判断分位对错。
   先例：本次 `audit_convention_diff.py` → 防御 flag 近 250 天 33 天 off→on、regime 标签 0 变。

## 6. 红线（这次定，长期守）

- ❌ 不重抓历史新闻/情绪/基本面重算（§3）。
- ❌ 不在看到回算结果后调任何判据/阈值/窗口（§2）。
- ❌ 不靠"观察几天/感觉信号对不对"给生产签字——读数据的判断交确定性回算，
  用户只判人话结论自洽性。
- ❌ 不急着合积压 PR（#37/#41 等）：根因改历史 regime 序列，下游验收/账本依附旧口径，
  先定根因口径→全部下游对齐→一起合，否则修两遍合两遍。
- ⚠ regime-lock"方向锁=杠杆旋钮"**只作相对结论**（三链同输入比较，污染下仍成立）；
  其依附的 regime 序列口径有偏，**不作任何绝对判断**。
