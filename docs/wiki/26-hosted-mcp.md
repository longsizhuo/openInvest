# 官方托管 MCP

本功能由运营者部署后开放；仓库中的实现不代表公网服务已上线。默认关闭公开注册。

## 三种部署方式

| 方式 | 账本位置 | 官方研究采集 |
|---|---|---|
| 本地 CLI / stdio MCP | 用户机器的 INVEST_HOME | 不自动发送 |
| 私有远程 HTTP MCP | 用户指定主机 | 不自动发送 |
| 官方托管 MCP | 新加坡服务端，每账户独立数据卷和容器 | 完成网页说明后按网页设置记录 |

官方服务免费，每人独立保存持仓、现金、策略、交易和决策。Google 与 GitHub 分别对应独立身份，不按邮箱合并。用户 Agent 负责推理；服务端不启用 TokenHub、付费模型或真实订单执行。

## 接入

1. 运营者发布的 `/connect/` 页面展示数据说明；Google / GitHub 登录。
2. 确认基准币种、风险偏好、至少一个关注标的；可以从空持仓开始。
3. 添加页面提供的 HTTPS `/mcp` 地址。ChatGPT 网页及支持 OAuth 的终端使用授权流程；其他客户端使用网页生成的个人访问凭证。凭证只展示一次。
4. Agent 使用 `prepare_committee` 获得 `analysis_id`，推理后随 `submit_committee` 提交。每账户仅允许一个待处理分析；账本或规则变化后需重新准备。

全部非幂等金额写操作必须提供 `idempotency_key`。相同账户和键的重试返回原结果；不同参数拒绝。断流后结果不确定时不会自动重放，需先检查账本。键按账户隔离。

## 网页数据说明

官方服务长期保存个人账本。研究记录默认开启，但仅在用户完成网页说明步骤后生效。研究数据用于研究、模型评估及未来训练，归档至新加坡 COS；没有自动训练或上线模型的任务。

研究数据为**去标识化数据**，不承诺完全匿名。保留实际收到的精确金额、币种、允许的业务参数与结果、分析关联、输入快照、规则/提示词版本和耗时。客户端自报的品牌和模型信息单独标记，无法验证的版本保持未知。

服务看不到完整聊天、未传入的目标、最终回答或未回传的采纳情况，不进行推测。工具成功、用户采纳和后续上涨不直接作为正确标签。仅调用工具为调用样本；提交了分析才可能形成决策样本，未经人工审核不导出训练集。

研究结构化字段采用白名单，文本经过敏感标记替换并进入加密隔离区，管理员审核清理后才进入训练导出。研究库不保存登录身份、邮箱、IP、凭证；身份与参与者编号映射只在独立控制库中。加密和去标识化不保证自由文本不存在再识别风险，公开数据集前仍需审核。

在网页设置中可以：

- 停止后续研究记录，取消待归档样本；账本和委员会照常使用。
- 单独删除尚未用于训练的研究样本；涉及的未训练导出同时失效。对象存储删除失败会保留待删除标记并重试。
- 导出账本和决策，撤销访问凭证及 OAuth 连接，删除账本并注销账户。

关闭记录不自动删除已归档样本；注销账户与删除研究样本是不同操作。已训练模型不承诺回溯遗忘。备份加密保留 30 天；控制库恢复后撤销全部连接、停止研究并重新要求网页确认；研究库恢复时丢弃未训练候选，避免从旧备份恢复已删除样本。

## Agent 上下文

告知、保存期限和研究设置只出现在网页与文档中，不写入技能、插件、MCP 初始化 instructions、工具描述或业务返回。只传正常认证、业务参数和 analysis_id；不要求 Agent 转述研究说明或补充研究反馈。

## 第三方与网站统计

用户 Agent 及其模型提供商会接收用于分析的工具结果和上下文，并有独立数据规则。Auth0 / Google / GitHub 只参与登录，不接收账本和研究轨迹。行情服务会收到查询标的。

账户、连接和设置页面采用独立站点构建，不加载 Umami 或全局复制统计；凭证、表单、OAuth 回调及决策文本不进入埋点。营销页面保留原有统计。

部署、备份、审核与验收见 [deploy/hosted/README.md](https://github.com/longsizhuo/openInvest/blob/main/deploy/hosted/README.md)。
