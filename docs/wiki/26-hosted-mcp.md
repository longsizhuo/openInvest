# 官方托管 MCP

本功能由运营者部署后开放；仓库中的实现不代表公网服务已上线。默认关闭公开注册。

## 三种部署方式

| 方式 | 账本位置 | 官方研究采集 |
|---|---|---|
| 本地 CLI / stdio MCP | 用户机器的 INVEST_HOME | 不自动发送 |
| 私有远程 HTTP MCP | 用户指定主机 | 不自动发送 |
| 官方托管 MCP | 新加坡服务端，每账户独立数据卷和容器 | 完成网页说明后按网页设置记录 |

官方服务免费，每人独立保存持仓、现金、策略、交易和决策。同一账户可在账户设置中绑定 Google 和 GitHub；绑定时分别验证身份，不按邮箱自动合并。用户 Agent 负责推理；服务端不启用 TokenHub、付费模型或真实订单执行。

## 接入

1. 运营者发布的 `/connect/` 页面展示数据说明；Google / GitHub 登录。
2. 在网页查看简短的数据说明和隐私政策，点击同意并继续；从客户端发起时可直接同意并授权。研究记录默认开启，关闭入口位于账户设置的「隐私与数据」。此步骤没有账本表单或阅读勾选。
3. 添加页面提供的 HTTPS `/mcp` 地址。ChatGPT 网页及支持 OAuth 的终端完成连接授权；其他客户端使用网页生成的个人访问凭证。凭证只展示一次。授权不依赖账本是否已建立。
4. Agent 首先调用 `doctor`。账本未建立时，向用户确认基准币种，再调用 `setup_ledger`。风险偏好可以保持未设置，关注列表和持仓可以为空。网页首次接入和未初始化账户页均不显示创建表单；初始化与既有记录导入交由 Agent 处理。建立账本后可在网页账户设置修改偏好。
5. Agent 使用 `prepare_committee` 获得 `analysis_id`，推理后随 `submit_committee` 提交。每账户仅允许一个待处理分析；账本或规则变化后需重新准备。

普通网页登录后进入 `/account/` 个人主页，查看账本状态、偏好摘要及已授权连接；客户端发起的 OAuth 继续在 `/connect/` 完成。个人主页不展示首次填写表单，未建账本时不加载个人容器。账户设置位于 `/account/?view=settings`。

网页账户设置和 MCP 的 `ledger_settings` / `update_ledger_settings` 读取、修改同一份偏好。更新需携带当前 `revision`，冲突时重新读取，不覆盖其他客户端的新修改。关注列表的增删不改变持仓或流水；既有标的的额度、提醒等信息保留。风险偏好影响后续分析，不回写历史决策。基准币种只允许在无资产、财务流水或决策记录时修改；有历史的币种迁移暂不支持。

全部非幂等金额写操作必须提供 `idempotency_key`。相同账户和键的重试返回原结果；不同参数拒绝。断流后结果不确定时不会自动重放，需先检查账本。键按账户隔离。

在无桌面 Linux 上，若 Codex 删除文件中保存的 MCP OAuth 凭证时出现 keyring 错误，可显式选择文件存储后重试。以下方式已在 Codex CLI 0.165.0 验证，`openinvest` 需替换为已配置的 MCP 服务器名称。存储选项见 [Codex 配置说明](https://learn.chatgpt.com/docs/config-file/config-reference)。

```sh
codex mcp logout openinvest -c 'mcp_oauth_credentials_store="file"'
```

服务端访问权限可在「个人主页 → 连接 → 撤销授权」中撤销。

## 网页数据说明

官方服务长期保存个人账本。研究记录默认开启，但仅在用户完成网页说明步骤后生效。研究数据用于研究、模型评估及未来训练，加密归档至 Cloudflare R2，存储位置采用服务商默认规则；没有自动训练或上线模型的任务。

研究数据为**去标识化数据**，不承诺完全匿名。保留实际收到的精确金额、币种、允许的业务参数与结果、分析关联、输入快照、规则/提示词版本和耗时。客户端自报的品牌和模型信息单独标记，无法验证的版本保持未知。

服务看不到完整聊天、未传入的目标、最终回答或未回传的采纳情况，不进行推测。工具成功、用户采纳和后续上涨不直接作为正确标签。仅调用工具为调用样本；提交了分析才可能形成决策样本，未经人工审核不导出训练集。

研究结构化字段采用白名单，文本经过敏感标记替换并进入加密隔离区，管理员审核清理后才进入训练导出。研究库不保存登录身份、邮箱、IP、凭证；身份与参与者编号映射只在独立控制库中。加密和去标识化不保证自由文本不存在再识别风险，公开数据集前仍需审核。

在网页设置中可以：

- 停止后续研究记录，取消待归档样本；账本和委员会照常使用。
- 单独删除尚未用于训练的研究样本；涉及的未训练导出同时失效。对象存储删除失败会保留待删除标记并重试。
- 导出账本和决策，撤销访问凭证及 OAuth 连接，删除账本并注销账户。

关闭记录不自动删除已归档样本；注销账户与删除研究样本是不同操作。已训练模型不承诺回溯遗忘。备份加密保留 30 天；控制库恢复后撤销全部连接、停止研究并重新要求网页确认；研究库恢复时丢弃未训练候选，避免从旧备份恢复已删除样本。

## Agent 上下文

告知、保存期限和研究设置只出现在网页与文档中，不写入技能、插件、MCP 初始化 instructions、工具描述或业务返回。只传正常认证、业务参数和 analysis_id；不要求 Agent 转述研究说明或补充研究反馈。

## 第三方与网站统计

用户 Agent 及其模型提供商会接收用于分析的工具结果和上下文，并有独立数据规则。Auth0 / Google / GitHub 只参与登录，不接收账本和研究轨迹。行情服务会收到查询标的。

账户、连接和设置页面采用独立站点构建，不加载 Umami 或全局复制统计；凭证、表单、OAuth 回调及决策文本不进入埋点。营销页面保留原有统计。

部署、备份、审核与验收见 [deploy/hosted/README.md](https://github.com/longsizhuo/openInvest/blob/main/deploy/hosted/README.md)。


## 登录方式与已有账户迁移

账户设置支持绑定与解绑登录方式。至少保留一种方式；解绑当前方式前，应先使用另一已绑定方式登录。绑定需要重新验证当前身份和待绑定身份，最终确认前不变更归属。

若另一身份已有账户，确认后保留发起账户及其账本、隐私偏好和已有凭证。另一账户的账本单独归档，可从账户设置导出，不自动合并交易。另一账户的会话、PAT 和 OAuth 授权全部撤销，研究记录停止新增，待处理研究样本取消。希望保留另一账本时，应取消并从另一账户发起关联。归档账本不通过 MCP 暴露；注销账户时一并删除。删除未训练研究样本的入口覆盖关联前的研究身份。

升级自动将旧身份映射迁移到独立绑定表，保持账户 ID、数据卷、账本、幂等记录及隐私设置不变。操作与恢复说明见 `deploy/hosted/ACCOUNT_IDENTITIES.md`。
