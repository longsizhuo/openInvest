## 承诺条款

### 条款 1 — openInvest 账户严格跟随委员会
- 黄金 + NDQ 这两个仓位**只按委员会建议执行**，不基于个人情绪做反向操作。
- 「反向操作」明确指（先钉死定义，免得事后狡辩）：
  - 委员会 HOLD，我却清仓 / 大幅减仓；
  - 委员会 TRIM/SELL，我却加仓；
  - 委员会没发话（没有当日 verdict），我凭感觉手动调仓。

### 条款 2 — 激进冲动隔离在系统之外
- 想梭哈、抄底、追涨、对赌的冲动，**一律走其他账户或渠道**，绝不进 openInvest。
- openInvest 是我的「冷静账户」；它的边界，就是我情绪的防火墙。

### 条款 3 — 触发情景 → 先回看本 ADR 再动手
出现以下任一念头时，**先回到这份文件从头读一遍，再决定是否操作**：
- [ ] 浮亏，想割肉离场，或想"摊低成本"乱加仓
- [ ] 看见别的资产 / 别人在涨，FOMO，想调仓去追
- [ ] 觉得"系统太怂 / 太保守"，想自己手动激进一把
