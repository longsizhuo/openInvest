# 17 · 闭环回测与委员会 skill 结论

> 2026-06-27。复现包 + 原始数据:`experiments/closed-loop-skill-test/`。方法论前提:`adr/022-backtest-memory-contamination-and-holdout-discipline.md`。

## 一句话结论
**openInvest 委员会是个讲纪律、会避险的风控者,不是 alpha 机器** —— 至少在牛市里,它的主动管理略微拖累收益、略微压低回撤。**绝不要拿回测"alpha"做营销**:那个数在空桩回测里是执行假象,在干净闭环回测里是负的。

## 怎么得到的
holdout(2025-01→2026-03,post-cutoff 无记忆穿越)上跑两版:
- **基线(空桩)**:回测 portfolio 硬编码中性(ADR-022 T3)→ 委员会看不到自己的仓位 → 从不减仓(perma-bull)。
- **闭环**:每日把模拟器**当前真实仓位**喂回委员会 prompt → 它能像 live 一样减仓。

| | 基线空桩 | 闭环 |
|---|---|---|
| alpha vs 同资产 buy-hold | +11.57% | **−2.58%** |
| MaxDD | 13.32% | **11.30%** |
| TRIM 执行 | ~0 | 16 |

## 两个必须记住的判读
1. **基线那个 +11.57% alpha 是假的**——执行机制意外(现金 day1-2 花光、碰巧没买到后来跑输的 NDQ),不是决策。**任何"空桩回测 alpha"都不可信。**
2. **闭环修复有效但揭示无正 skill**:委员会看到真实仓位后确实减仓(TRIM 16、MaxDD↓),但减仓在牛市=卖飞 → **真实 alpha −2.58%(跑输 buy-hold)**。"少亏的代价是少赚"是防御型策略签名。

## 对产品 / 方法论的影响
- **定位**:对外讲"透明、有纪律的风险管理 + 决策过程可审计",**不讲"跑赢/选股/alpha"**。与 README 现有诚实口径(~25% 方向命中、84% HOLD、"不会让你致富")一致。
- **回测纪律**:测 skill 必须用**闭环**(喂真实仓位);空桩回测只反映"市场 beta + 执行假象",verdict 分布退化成 perma-bull,不可外推 live。`scripts/backtest_committee.py:run_one_day` 已加 `portfolio_summary_override` / `out_subdir` 钩子支持闭环。
- **对照专业机构**:同期招行私行(参考语料,本地)对黄金 2025Q1 主动降档、对美股全程标配——**有区分度**;我们委员会逐季一律偏多,**更钝**。

## 没解决的(后续)
- 窗口几乎全是上行市 → de-risk skill 没舞台。**要盖棺需含真实暴跌的 post-cutoff 窗口**(暂无);污染段(2008/2020)只能看减仓**行为**一致性,不是干净 P&L。
- 单次蒙特卡洛(MiMo 有温度无 seed)→ 应同窗口重跑 ≥5 次报 CI。
