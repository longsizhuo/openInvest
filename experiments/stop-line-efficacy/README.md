# stop-line-efficacy — CIO 备忘里的"跌破 X 就减仓"有没有预测力

**结论：不采纳。** 不要把 CIO 散文里的止损线做成结构化字段 + price_sentinel 监控。

## 为什么问这个

2026-08-19 快手财报后，as-of 重放显示委员会两次都给 HOLD，但两次都在备忘里写了
条件卖出线（"-15% 止损约 HK$36.4"、"跌破 35 港元减仓 50%"），而 8/20 收 33.92
把两条线都击穿了——系统里没有任何东西在盯这些线。做不做这个监控，取决于线本身
是不是噪音，所以先回算。

跑法：`uv run python scripts/audit_stop_line_efficacy.py`（零 LLM，纯价格回算）。
判据在跑之前冻结，写在脚本 docstring 里。

## 结果（2026-08-20）

语料 A = `memory/.backtest/` 未污染样本（primary，n 大）；
语料 B = `memory/.committee/` 真实持仓样本（secondary）。

| | A 回测语料 | B live 语料 |
|---|---|---|
| HOLD transcript | 47,880 | 142 |
| 其中写了绝对价卖出线 | 476 (1.0%) | 64 (45%) |
| 过单位/合理性过滤 | 361 | 24 |
| 20 交易日内被击穿 | 134 (37%) | 4 (17%) |
| 击穿后 +5d 中位收益 | **+1.12%** | −6.11% (n=2) |
| 击穿后 +20d 中位收益 | **+1.26%** | −3.86% (n=1) |
| +20d 超额（对同 symbol 无条件基线） | **+0.09pp** | — |
| +20d 为负的比例 | **45.5%** | — |
| 冻结判据判定 | **不采纳** | **样本不足** |

A 组 n=132 满足样本量要求，但方向完全不成立：击穿之后 20 日中位收益是**正的**，
比同标的无条件基线还高 0.09pp，负收益占比 45.5%——跟抛硬币没区别。按这条线减仓
平均而言是卖在短期坑里。

B 组只有 1~2 个完整窗口（快手那两条恰好难看），按冻结判据**不予采纳**，不拿它讲故事。

## 限制（如实记，但不用来推翻上面的判定）

- **单位过滤丢样本**：A 组丢 113 条、B 组丢 40 条，主要是 GC=F 备忘写 ¥/克而行情是
  USD/oz。黄金因此在样本里代表性不足。
- **regime 单一**：语料覆盖 2025-06→2026-08，以美股新高 + 黄金 4000→4550 的多头
  环境为主，均值回归天然占优。这个判定只对这个 regime 成立，数据里没有熊市段可测。
- **只测"击穿后价格怎么走"**，没有建模减仓后的买回，也没算交易成本。但既然击穿后
  中位收益是正的，加上成本只会更差，不影响结论方向。
- **v1 解析器作废**：第一版正则全文取"跌破/止损 + 数字"首个命中，抽检 8 条有 5 条
  误抓（"美元指数跌破100" 的 DXY、"跌破1300…可转为 ACCUMULATE" 的买点）。v1 数字
  不可用，已被 v2 替换；**判定规则未随之改动**。
  顺带更正一个之前对外说过的数字：早先说"76% 的 HOLD 备忘写了触发线"用的就是 v1
  那个坏正则，虚高。真实是 live 语料 45%、回测语料 1.0%。
