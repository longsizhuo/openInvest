# 委员会能力基线(2026-07,全库干净桶 n=98,647)

第一份大样本、零记忆穿越的委员会能力画像。数据来自 L1-L4 历史回填语料
(`memory/.backtest`,768 标的 × 337 交易日 = 143,456 份 transcript),
由 `jobs/verdict_review` 用真实后市判卷(141,421 条已评分)。

## 口径

- **干净桶** = 决议日 > `CONTAMINATION_CUTOFF`(2025-05-31,deepseek-v4-flash
  自报训练截止,ADR-022 更新节实测):模型没见过这段行情,业绩只从这里报
- **降级桶**(2025-01→05,41,966 条)= 模型可能背过后市,只作一致性检查
- 命中定义(`review_calc`):BUY/ACC 后涨=对,SELL/TRIM 后跌=对,HOLD 波动<3%=对;
  事后 30 天 VIX/利率剧变标记 macro_shock 并单列
- 组合画像是中性空桩(ADR-022 §6),verdict 分布不可外推 live 用户

## 命中率

| 窗口 | 全体 | 剔除宏观突变 |
|---|---|---|
| 1d | 72.6%(n=98,629) | 73.1% |
| 7d | 75.7% | 76.2% |
| **30d** | **66.0%** | **68.3%**(n=80,683) |

分 regime(30d):uptrend 67.9%(n=32,293)> range_bound 66.2%(n=55,368)
> downtrend 63.5% > crash 55.7% > **recovery 54.9%**(n=4,468,最弱项——
反弹段踏空,与过度保守自洽)。

分层(30d):L1 66.2% / L2 66.1% / L3 64.7% / L4 73.5%(n=8,923,中断层样本
偏 S&P500 成分,不与前三层可比)。**L1→L3 宇宙从 50 扩到 340 标的,命中率
仅 -1.5pp——能力是系统性的,不是挑标的挑出来的。**

## 塌缩:治疗前照片

干净桶 98,647 条决议的 verdict 分布:

| verdict | 占比 |
|---|---|
| HOLD | 47.5% |
| ACCUMULATE | 38.3% |
| **UNCLEAR** | **14.2%** |
| TRIM | 0.0%(个位数) |
| **BUY / SELL** | **0 条** |

中性画像下委员会**从不说 BUY 或 SELL**。这是 ADR-007 要治的过度保守第一次有
统计功效的量化基线,也是 path_v4 教材(五档全活:HOLD 34/SELL 27/BUY 18/
ACC 12/TRIM 9)的对照组。

**UNCLEAR 14.2%(约 1.4 万条)**是 CIO 自由文本没被正则解析出 verdict 的残次品,
比早期抽样估计的 3.1% 高得多——生产改造(计算式仓位 + CIO 尾段 JSON 输出)
应把它压到 0,这本身就是一笔可观的质量回收。

## 用途

1. 任何委员会改动的**对照基线**(同口径重跑即可对比)
2. path_v4 计算式仓位上生产后的**验收标准**:五档是否复活、UNCLEAR 是否归零、
   30d 命中率是否守住 66%
3. 语料本身(含四角色辩论全文)可作 few-shot demo 池,按 (date, symbol) 与
   教材 `dspy_trainset_v5.jsonl` 逐条 join

花费:约 ¥330(36.4 万次 API 请求 / 12.2 亿 token,实测单次委员会 ≈ ¥0.002)。
