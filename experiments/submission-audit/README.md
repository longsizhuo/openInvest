## 统计与表述修正

- 98,647 不是 Brier 或区间覆盖率的通用分母。按实验、来源、模型、窗口、成熟度、
  解析状态、污染状态、周末重复、实际指标分母分别报告，附筛选 flow table。
- 768×337=258,816，并非文档的 143,456：应解释为稀疏覆盖；141,421 已评分与
  98,647+41,966 之间的 808 行差额待核，不臆测为缺失或污染。
- 训练截止日是模型相关假设。事件探针“不知道”仅是未检出记忆，不是未训练证明；
  需逐行模型版本、运行时间、发布说明与 cutoff 证据。真正 prospective 决策需时间戳
  先于结果，并与历史 backfill 分桶；周末重复、同日 macro 共享也要标注。
- TA coverage 是表态比例。基线③不是配对样本的胜率差检验；Wilson 未处理时间相关，
  15 个单格应说明多重比较与跨模型 Gate 的区别。不能把负结果或未显著写成等价证明。
- confidence 恒定只能说明该范围内没有区分能力；常数概率仍可能校准良好，不能
  单由方差为零推出“概率不可信”。置信度的事件语义须固定，HOLD 的命中定义与
  flat band 版本要记录，不能把方向准确率当所有 verdict 的统一事件。

|---|---|

| live verdict_review | 即使去姓名也可由日期+资产+动作重识别账户；优先只发整体足量聚合，必要时用合成输入替代 |
| variance 逐次记录 | 先删除标的、日期、金额、原持仓与自然语言，再评估跨文件重识别；保留随机输入 ID、run ID、confidence/错误状态与输入哈希以支持算术复核 |
