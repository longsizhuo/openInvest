# exit-signal-study — 价格类离场信号有没有边际（2026-08-24 冻结）

## 起因

生产委员会 250 次裁决里 **SELL 0 次、BUY 0 次**，某港股单股 22 次裁决里 TRIM 0 次、
ACCUMULATE 4 次。排查发现"离场"这个动作被四道锁锁死（详见 ADR）。修之前先回答一个
前置问题：**价格类离场信号本身有没有信息量？** 如果没有，那修的方向就不是加止损触发器。

## 方法

纯价格事件研究，零 LLM、零网络、无前视（t 日只用 ≤t 的收盘价）。

- 样本：`experiments/paper_fleet/universe.yml` 的 50 个横截面标的，**302,418 个无条件交易日**
- 信号（只记穿越/达成当日，不重复计入整段）：
  - `DD_X`：从过去 252 日滚动最高点回撤首次跨过 X%（X = 10/15/20/25，第二轮补 40/50/60）
  - `MA120`：收盘从 ≥MA120 变成 <MA120 的那一天
  - `PERSIST_N`：收盘连续在 MA120 下方达到 N 个交易日（N = 60/120，第二轮）
- 前瞻窗口：20 / 60 / 120（第二轮加 250）个交易日
- 基准：同一批标的、同一可用区间内**所有**交易日的无条件前瞻分布

### 判据（跑前冻结，事后未调）

某信号称得上"有信息"需**同时**满足：
1. 60 日中位前瞻收益比无条件低 **≥ 2 个百分点**
2. 60 日 P(前瞻收益 < 0) 比无条件高 **≥ 5 个百分点**

第二轮的 DD40/50/60 与 PERSIST 是**单独声明的扩展**（第一轮桶只到 25%，不覆盖 −60% 这种
深跌状态），判据与第一轮完全一致，结果无论好坏照报。

## 结果：全军覆没

paper_fleet 50 标的（`data/round1_output.txt` / `round2_output.txt` 为原始输出）：

| 信号 | 60d 中位差 | P(<0) 差 | 判定 |
|---|---|---|---|
| DD10 / DD15 / DD20 / DD25 | +0.3 / +1.2 / +0.6 / +2.4pp | +2.2 / +0.7 / +3.4 / −0.1pp | 全不构成 |
| DD40 / DD50 / DD60 | +0.9 / +2.0 / +9.5pp | +6.6 / +3.9 / −1.6pp | 全不构成 |
| MA120 下穿 | −0.3pp | +2.7pp | 不构成 |
| PERSIST60 / PERSIST120 | −0.0 / −1.5pp | +3.0 / +5.7pp | 全不构成 |

**一条都没过判据**，且多数方向是反的——信号触发后前瞻收益比无条件**更好**（均值回归）。
深度回撤尤其明显：DD60 后 250 日中位 **+41.1%**，P(120d < −20%) = 18%（无条件 6%）。

港股子集（DD40 −13.1pp / DD50 −7.4pp / PERSIST60 −7.8pp）判为"有信息"，**但不采信**：
只有 4 个标的、n = 22~98、窗口高度重叠，实质是 2021-22 中概监管**一个宏观事件**，
不是独立样本。

## 已知局限（对本结论不利，必须一起讲）

- **幸存者偏差**：universe 是今天仍在交易的 50 个标的，真正归零/退市的不在池子里
  → 本研究**系统性低估**离场的价值。真实边际比 0 大，但不足以支撑一条机械止损线。
- 重叠窗口有强自相关，n 大 ≠ 独立样本多；本研究只报分布差，**不报 p 值**。
- 只测了价格类信号，**没测**基本面信号（那需要 point-in-time 财报数据，且不能重抓）。

## 结论

1. **不要做机械止损**（含"把 CIO 备忘里那条止损线结构化 + 哨兵盯着"这条路——
   166 份 HOLD transcript 里 126 份写了具体价格触发线，但按线离场是噪音交易）。
2. 该修的是**表达能力**不是触发器：价格既然没边际，唯一能证成离场的是基本面判断，
   而那正是被锁死的能力。护栏应当是"出 exit 必须引用具体基本面事实，不得只凭价格技术面"。
